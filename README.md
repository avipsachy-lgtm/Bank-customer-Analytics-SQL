#  Bank Customer Analytics SQL Project

## Project Status
 In Progress

## Objective
Analyze customer, account, transaction, and loan data using SQL to generate business insights for banking operations.

## Dataset
The project contains:

- Customers
- Accounts
- Transactions
- Loans
- Branches

## SQL Skills Demonstrated

- SELECT Statements
- WHERE Clauses
- GROUP BY & HAVING
- JOINS
- Subqueries
- CTEs
- Window Functions
- Aggregate Functions

## Business Questions

1. Top customers by account balance
2. Dormant customer identification
3. Branch-wise deposit analysis
4. Monthly transaction trends
5. Loan portfolio analysis
6. Customer segmentation

- SQL
