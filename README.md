#  Bank Customer Analytics SQL Project


**Project Overview**

This project analyzes banking customer data using SQL to generate actionable business insights related to customer behavior, account performance, transaction activity, loan distribution, and branch performance.
The analysis helps identify high-value customers, dormant accounts, transaction trends, customer retention, and loan distribution patterns, enabling data-driven decision-making in the banking sector.

## Project Status
 In Progress

## Objective
Analyze customer, account, transaction, and loan data using SQL to generate business insights for banking operations.

## Dataset
The project contains:

•	Customers – Customer demographic information
•	Accounts – Account details and balances
•	Transactions – Deposit and withdrawal transactions
•	Loans – Customer loan information
•	Branches – Branch details and locations

## Business Questions

1. Top 10 High-Value Customers
Identified customers with the highest account balances and transaction values.
2. Dormant Customer Identification
Detected customers with no transactions within a specified period.
3. Monthly Transaction Analysis
Analyzed monthly transaction volume and transaction amounts.
4. Branch-wise Deposit Analysis
Compared total deposits across different branches.
5. Customer Segmentation
Segmented customers based on account balance and transaction behaviour.
6. Loan Distribution Analysis
Examined loan amounts and loan types across customer groups.
7. Running Balance Calculation
Used window functions to calculate running account balances.
8. Customer Retention Analysis
Measured customer activity trends and retention patterns over time.

**Key Insights**
•	Identified the most valuable banking customers.
•	Tracked inactive customers for re-engagement campaigns.
•	Evaluated branch-level performance.
•	Analyzed customer loan behavior.
•	Monitored transaction growth trends.
